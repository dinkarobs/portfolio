Parts of Html?

HyperText Hypertext is an electronic text format that enables users to navigate between linked objects, which may include text, images, audio, videos, and other multimedia elements.
Markup Language A markup language is a system that uses tags or codes to structure, format, and add meaning to digital text, telling computers how to display or process content like headings, links, and paragraphs.
HTML a standardized system for tagging text files to achieve font, color, graphic, and hyperlink effects on web pages.
DOCTYPE What you need to start a HTML webpage, "< !DOCTYPE >"
Title Creates the title, "< title >"
Tags Start making tags by inputting "<>"
Head The first tag you make is a "< head >" tag which is what the user cant see
Body What the user can see (text) is called the "< body >"
Header How you create a header, "< h1 >"(its h1-h6)
Table How you create a table, "< table >"
Table row(TR) How you create a table row, "< tr >"
TD Creates a table column, "< td >"
Table header(th) How you make a table header, "< th >"
Details Creates a disclosure widget, which can show or hide additional information or controls on demand, "< details >"
Summary Creates a summary inside of details, "< summary >"
Paragraph Defines a paragraph of text, "< p >"
OL Ol creates an ordered list that orders your text by number, "< ol >"
UL Ol creates an ordered list that orders your text by bulleted points, "< ul >"
LI LI allows you to add text into your "OL" and "UL", "< li >"
A "a" allows you to put a link down which allows you to go to any page you set it as, "< a >"
LINK defines a relationship between the current document and an external resource. Unlike the "< a >" (anchor) tag, which creates clickable hyperlinks for users, "< link >"
IMG "img" is used to add an image of your choice on the page, "< img >"
META provide metadata—information about the document that is not displayed on the page but is readable by machines, such as web browsers and search engine crawlers, "< meta >"
NAV semantic tag used to define a section of a page that contains major navigation links.
BR the "br" tag is used to insert a single line break within a block of text, "< br >"
